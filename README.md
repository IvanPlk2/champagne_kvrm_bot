# KVRM Telegram Bot

Telegram-бот команды «Советское Шампанское» (KVRM): турниры, составы, опросы о готовности и анонсы.

Основная работа — в личке с ботом. Опросы живут в командном чате.

## Возможности

### Для игроков

- свои будущие турниры и состав («с кем играю»);
- просмотр опроса: база и админы видят все, легионер — только игры, где есть его голос;
- настройки: включить или выключить личные уведомления.

Готовность берётся из опроса в командном чате. Любой голос (в том числе «Нет») пишется в базу — так легионер остаётся привязан к игре.

### Для базы и админов

- игры: добавить синхрон или фестиваль с сайта рейтинга (поиск, клавиатура ближайших турниров или ID), указать место и время, править и удалять;
- после добавления игры бот спрашивает, создавать ли опрос;
- опросы: создать в командном чате и закрепить, показать существующий;
- список ближайших турниров команды;
- сообщение для чата легчата: у базы кнопка на главном экране, у админа — в меню «Игроки»;
- подписка на предложения из канала WeekChgkSPB (только база, включается в настройках).

Списки игр в меню ограничены **10** записями: это потолок обычной недели. Редкий случай — через ID.

### Только для админов

- привязка Telegram-игрока к профилю на сайте рейтинга;
- права: админ и база.

`SUPER_ADMIN` (необязательно) — `base_id` игрока в рейтинге, у которого нельзя забрать права админа.

### Оповещения

- в командный чат: «собран состав» при шести готовых; «разобрался состав», если через минуту после снятия голоса снова меньше шести (после рестарта бота незакрытые проверки поднимаются снова);
- в личку готовым игрокам с включёнными уведомлениями: смена места или даты, отмена игры; для обычной игры — напоминание за сутки и за 2 часа до `date_start`, для фестиваля — только за сутки до начала окна с рейтинга;
- опрос закрепляется в командном чате и открепляется в **10:00 МСК** на следующий день после игры, для фестиваля — на следующий день после `date_end`.

Застрявшую клавиатуру сбрасывает `/start`. Если бот не понял кнопку или ввод, он об этом напоминает.

## Стек

- Python 3.11+
- python-telegram-bot, SQLite
- API [rating.chgk.net](https://api.rating.chgk.net) (сайт рейтинга)

`postgres_db.py` и `psycopg2` оставлены для совместимости и в работу бота не входят.

## Установка

```bash
pip install -r requirements.txt
python bot.py
```

## Конфигурация

Секреты только через окружение, не коммитьте `.env`.

| Переменная | Назначение |
| --- | --- |
| `API_KEY` | токен Telegram-бота |
| `SQLITE_PATH` | путь к файлу SQLite |
| `TEAM_CHAT_ID` | командный чат (опросы, состав, закрепление) |
| `ANOTHER_CHAT_ID` | прежний id того же чата, если группа стала супергруппой |
| `TEAM_NAME` | название команды |
| `TEAM_ID` | id команды на сайте рейтинга |
| `SUPER_ADMIN` | необязательно, `base_id` суперадмина |

Для опросов и закрепления боту нужны права администратора в командном чате. После выдачи прав чат часто становится супергруппой и меняет id — отсюда два идентификатора.

## Структура

- `bot.py` — запуск, маршрутизация команд, кнопок и callback
- `config.py` — переменные окружения
- `const.py` — кнопки, состояния, callback
- `sqlite_db.py` — данные
- `handlers/` — клавиатуры, игры, опросы, игроки, напоминания, состав, настройки
- `announce_offers.py`, `week_announces.py` — разбор ленты анонсов
- `rating_api.py` — клиент API рейтинга

Проект не является официальным продуктом Telegram или сайта рейтинга и не аффилирован с ними.

# KVRM Telegram Bot

Telegram-бот для управления турнирами КВРМ, участниками команды и опросами о готовности играть.

## Возможности

- добавление турниров с сайта рейтинга;
- добавление фестивалей с сайта рейтинга;
- привязка Telegram-пользователя к профилю на сайте рейтинга;
- просмотр будущих турниров;
- управление готовностью игроков участвовать в турнирах;
- создание и показ Telegram-опросов;
- уведомления команды о набранном составе;
- хранение данных в PostgreSQL.

## Требования

- Python 3.11+
- PostgreSQL
- Telegram Bot Token
- API-доступ к rating.chgk.info

## Установка

```bash
pip install -r requirements.txt
```

Создайте `.env` на основе `.env.example` и заполните значения.

Запустите бота:

```bash
python bot.py
```

## Конфигурация

Секретные параметры передаются через переменные среды. Не добавляйте `.env` в Git.

## Telegram

`TEAM_CHAT_ID` — идентификатор командного чата.

Боту потребуются соответствующие права в командном чате для функций, связанных с опросами и закреплением сообщений.

Основная работа с клавиатурами выполняется в личной переписке с ботом.

## rating.chgk.info

Проект использует API rating.chgk.info для получения информации о турнирах и игроках.

Проект не является официальным продуктом Telegram или сайта рейтинга и не аффилирован с ними.
